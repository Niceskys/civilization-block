## 本轮目标

待 Codex / 用户审核后回写。

本轮目标是整理《文明块》中“地下探索 / 挖掘 / 矿脉 / 工具门槛”和“地上基础城市闭环”之间的边界，避免后续出现两类问题：

1. 地下探索过早成为第一轮城市启动的硬门槛，导致玩家还没建好房屋、农田、水井、树场，就被迫理解矿脉、镐子、深度、矿石链。
2. 地下探索被削弱成无关内容，无法承担中期扩展、铁矿石来源、深层资源、风险探索和长期目标。

本建议的核心判断是：

> 地上基础闭环负责让城市活下来；地下探索负责让城市向下扩展、获得深层资源和进入中期专业化。

建议目标包括：

1. 明确地上基础闭环不应依赖地下挖掘才能启动。
2. 明确第一座房屋、农田、水井、树场不应要求玩家先挖地下。
3. 明确铁矿石 / 铁锭链可以成为中期扩展节点，但不应卡住第一轮基础生存。
4. 明确地下入口、矿脉、工具等级、挖掘深度应在玩家完成基础城市理解后逐步展开。
5. 明确地下探索可以带来资源、风险、事件和空间扩展，但不得绕过地皮归属、建造层、存档和权威模拟边界。
6. 明确后续 Codex 回写应先处理边界说明，再处理数值、工具、事件和实现。

## 建议写入内容

待 Codex / 用户审核后回写。

### 一、地上与地下阶段定位

建议未来在 `1.7 地下挖掘与探索系统.md` 中形成以下原则：

```md
### 地上与地下阶段定位

- 地上基础闭环负责新存档的生存启动，包括住房、基础食物 / 水、木材补给、基础人口响应和第一轮建造反馈。
- 地下探索负责中期扩展，包括铁矿石、特殊矿脉、深层资源、风险事件、工具价值和长期空间目标。
- 地下探索不得作为第一座房屋、第一座农田、第一口水井或第一座树场的前置条件。
- 玩家不进入地下，也应能完成基础城市启动闭环。
- 玩家进入地下后，应获得新的资源目标和风险回报，而不是重复地上基础采集。
```

### 二、地下入口出现时机建议

```md
### 地下入口出现时机建议

- 地下入口不应在前30秒强制弹出教学。
- 地下入口可以在玩家完成基础住房和至少一条基础生产链后出现提示。
- 地下入口可以通过地皮勘探、任务里程碑、建筑解锁、事件发现或矿脉显现逐步引出。
- 未拥有、未探索、未接入或未稳定的地皮，不应直接允许开挖地下入口。
- 地下入口必须绑定明确地皮和权威位置，不得只作为视觉装饰。
- 地下入口可以被 UI 标记为“可探索目标”，但不得阻塞地上基础建造。
```

### 三、浅层与深层边界建议

```md
### 浅层与深层边界建议

- 浅层地下可以承担基础铁矿石发现、少量洞穴、浅层事件和基础采掘教学。
- 深层地下可以承担铜矿石、水晶碎片、晶能宝石、危险事件、特殊地形和高阶工具价值。
- 浅层探索应在基础城市闭环后开放，不应要求玩家已经完成复杂工具链。
- 深层探索可以要求更高等级工具、建筑、工人或任务条件。
- 深度门槛应逐步展示，不得一次性把所有矿种、所有工具和所有风险塞给玩家。
```

### 四、工具门槛边界建议

```md
### 地下工具门槛边界

- 工具门槛可以限制地下深度、矿脉类型、采掘效率和危险处理能力。
- 工具门槛不得反向阻止地上基础建筑闭环。
- 第一轮基础城市启动不需要铁镐、铜镐、水晶镐或晶能镐。
- 铁镐可以作为浅层地下探索或基础矿脉采掘的门槛之一，但不应成为第一座房屋或第一座农田的前置条件。
- 铜镐、水晶镐、晶能镐更适合深层资源和中后期目标。
- 工具不足时，应显示“需要更高等级工具”或“当前只能探索浅层”，不得显示为系统错误。
```

### 五、铁矿石 / 铁锭进入节奏建议

```md
### 铁矿石 / 铁锭进入节奏建议

- 铁矿石和铁锭应作为城市从基础生存进入加工生产的重要节点。
- 第一座熔炉房冷启动不应要求玩家已经拥有大量铁锭。
- 铁矿石来源可以来自浅层矿脉、任务奖励、勘探奖励、商店或事件，但必须明确来源。
- 不得伪造铁矿石或铁锭产出；所有获得都应来自正式奖励、采掘、交易、事件或生产链。
- 铁矿石 / 铁锭任务不应排在基础住房、基础木材和基础生产之前。
- 铁锭链应帮助玩家理解“城市开始加工复杂资源”，而不是卡死前期基础建造。
```

### 六、地下探索任务建议

```md
### 地下探索任务建议

- 地下探索任务应出现在基础城市闭环之后。
- 适合的前置里程碑包括：第一座房屋完成、至少一名 NPC 入住、至少一座基础生产建筑运转、木材来源稳定。
- 地下任务可以引导玩家发现浅层矿脉、建造采掘相关建筑、获得第一批铁矿石或理解工具门槛。
- 地下任务不得要求玩家在前30秒打开地下界面或制造工具。
- 地下任务奖励应明确是任务奖励或探索奖励，不得伪装成建筑生产。
- 玩家自由发现地下入口或矿脉时，任务系统应自动识别，不要求按固定顺序重做。
```

### 七、地下 UI 反馈建议

```md
### 地下 UI 反馈建议

- 地下入口应显示所属地皮、当前可探索层级、工具需求和风险等级。
- 不可挖掘时，应给出明确原因，例如：未拥有地皮、未探索地皮、缺少入口、工具不足、危险未处理、建筑阻挡。
- 地下资源显示应保持阶段性，不应在初期直接暴露所有深层资源。
- 浅层、深层和特殊矿脉应有清晰视觉区分。
- 地下探索失败、暂停或等待时，应显示温和、可解决的原因，而不是系统错误。
```

### 八、风险事件边界建议

```md
### 地下风险事件边界

- 地下风险可以包括塌方、怪物、毒气、工具损耗、道路堵塞、资源枯竭或未知事件。
- 地下风险不应在玩家第一次进入地下前影响地上基础城市启动。
- 地下风险不应绕过第一夜无怪物、前期危机延迟或基础城市闭环保护。
- 浅层风险应低频、可理解、可恢复。
- 深层风险可以更强，但必须伴随更高收益和更明确预警。
- 地下事件不得直接摧毁地上基础闭环，除非正式中后期规则明确允许。
```

### 九、地上 / 地下权威状态边界建议

```md
### 地上 / 地下权威状态边界

- 地下格层、矿脉、入口、挖掘进度、工具消耗和资源产出必须属于权威模拟状态。
- 地下视觉表现、洞穴阴影、矿脉闪光、粒子、音效和镜头只解释权威状态。
- 关闭地下特效、降低画质或隐藏矿脉粒子，不得改变矿脉产出或挖掘结果。
- 地上建筑与地下空间的关系必须由正式规则校验，不得由视觉重叠直接决定。
- 存档必须能稳定恢复地下入口、已探索层级、矿脉状态、挖掘任务和等待原因。
```

## 理由

待 Codex / 用户审核后回写。

提出本建议的理由如下：

1. 地下探索是《文明块》中很有潜力的中期扩展内容，但如果过早进入，会压垮前30秒和基础城市闭环。
2. 玩家最初需要理解建造、NPC、住房、基础生产和资源栏，而不是立刻理解地下层级、矿脉、工具和风险。
3. 铁矿石 / 铁锭链对熔炉房和中期生产很重要，但不能把第一轮城市启动卡死。
4. 工具制造系统可以通过地下深度和矿脉类型体现价值，不需要提前卡住地上基础建筑。
5. 地下任务如果作为中期目标，可以给玩家明确成长方向；如果作为开局门槛，则会破坏自由建造体验。
6. 地下探索涉及资源、风险、地图、工具、UI、存档和事件，必须先确立阶段边界，再谈实现。
7. 本建议与基础城市闭环、工具制造前期边界、任务系统非强制边界和表现层权威状态边界相互配套。
