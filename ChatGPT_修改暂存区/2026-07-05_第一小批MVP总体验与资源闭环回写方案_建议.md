## 建议任务 S2：`4.2 生产链路总览.md`

### 文件现状

该文件是完整生产链路文件，已有树场、采掘场、熔炉房、农田、水井、垃圾处理场、燃料生产链、熔炉房冷启动、通用生产批次、存档与读档、Runtime 最小实现状态、科技、防御、设施等长期链路。

### 主要风险

该文件不是 MVP 专用文件。若直接写“生产链路就是基础闭环”，容易误伤全量设计，或者让后续 AI 以为全量链路都要进入 MVP。

### 建议小改方向

建议在 `# 生产链路总览` 后、现有 `## 生产链路` 前补充：

```md
## MVP 主循环子集

本文件维护完整生产链路总览。MVP 阶段只启用其中的最小主循环子集，不代表删除或废弃后续完整生产链。

MVP 基础城市闭环为：

木材驱动建造 → 房屋提供居住容量 → 水井提供水 → 农田消耗水并产出食物 → 城市按人口聚合消耗食物与水 → 空闲 NPC 以 MVP 劳动力规则参与施工 / 基础生产 → 树场提供可再生木材继续扩张。

MVP 主循环至少涉及：木材、食物、水、人口、空闲工人或等价劳动力状态、房屋、农田、水井、树场。

MVP 生产链停止在“树场提供可再生木材”。

以下内容属于后续完整生产链，不作为 MVP 第一版主循环要求：采掘场、铁矿石、铁锭、熔炉房、燃料链、垃圾处理场、肥料、太阳灯、科技点、管道、防御建筑、商店补货、任务奖励资源池、地下矿脉、工具制造链。
```

### 禁止事项

- 不删除现有完整生产链。
- 不删除燃料生产链。
- 不删除熔炉房冷启动。
- 不删除 Runtime 最小实现状态。
- 不把熔炉、铁矿石、铁锭、燃料、垃圾处理、科技、防御写成 MVP 必做。

## 建议任务 S3：`4.1 全资源清单.md`

### 文件现状

该文件是全资源清单，并维护稳定资源 ID。已有 16 种资源，包括食物、水、木材、石头、垃圾、铁矿石、铜矿石、水晶矿、铁锭、铜锭、水晶碎片、晶能宝石、星辉、肥料、燃料、科技点。

### 主要风险

不能因为 MVP 裁剪而删除全量资源表，也不能删除或重命名稳定资源 ID。

### 建议小改方向

建议在 `# 全资源清单（共16种）` 后、`### 基础资源（7种）` 前补充：

```md
## MVP 主循环资源子集

本文件维护完整资源清单和稳定资源 ID。MVP 阶段只启用其中的主循环子集，不代表删除其他资源。

MVP 主循环至少需要以下资源或状态项：

| 项目 | 类型 | MVP 作用 |
|---|---|---|
| 木材 | 库存资源 | 基础建造与继续扩张 |
| 食物 | 库存资源 | 维持人口，体现农田价值 |
| 水 | 库存资源 | 维持人口，并支撑农田生产 |
| 人口 | 城市状态 | 城市规模和住房容量反馈 |
| 空闲工人 | 劳动力状态 | 施工与基础生产岗位调度 |

人口和空闲工人不必作为普通库存资源处理，可由 NPC / 劳动力系统维护，但必须能在 MVP UI 中被清楚展示。

以下资源保留在完整资源清单中，但不进入 MVP 第一版主循环：石头、垃圾、铁矿石、铜矿石、水晶矿、铁锭、铜锭、水晶碎片、晶能宝石、星辉、肥料、燃料、科技点。

MVP 裁剪不得删除、重命名或复用现有稳定资源 ID。
```

### 注意事项

水井当前建造成本为 10 石头，石头不进入 MVP 主循环会形成冷启动风险。第一小批只记录资源子集，不直接裁决水井成本。水井冷启动应在后续 `6.1 建筑数值表` 或 MVP 初始资源裁决中处理。

### 禁止事项

- 不删除 16 种资源表。
- 不删除 Runtime 稳定资源 ID 表。
- 不把铁矿石、铁锭、燃料、肥料、科技点写入 MVP 主循环。
- 不在本文件直接修改水井建造成本。
