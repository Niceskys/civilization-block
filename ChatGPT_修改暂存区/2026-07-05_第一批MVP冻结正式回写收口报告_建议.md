## 本批确认冻结的 MVP 边界

### 1. MVP 首轮体验

MVP 前30秒只服务“让城市开始动起来”，不展示完整系统规模。

前30秒不得要求玩家首轮理解或操作：

- 正式任务系统；
- 商店系统；
- 地下探索；
- 工具制造；
- 科技树；
- 怪物 / 防御战；
- 完整 NPC 职业、情绪、记忆或社交；
- 联机入口；
- 模组入口。

### 2. MVP 基础城市闭环

MVP 基础城市闭环为：

```md
木材驱动建造 → 房屋提供居住容量 → 水井提供水 → 农田消耗水并产出食物 → 城市按人口聚合消耗食物与水 → 空闲 NPC 以 MVP 劳动力规则参与施工 / 基础生产 → 树场提供可再生木材继续扩张。
```

### 3. MVP 主循环资源 / 状态

MVP 主循环至少需要：

- 木材；
- 食物；
- 水；
- 人口；
- 空闲工人。

人口和空闲工人不必作为普通库存资源处理，可由 NPC / 劳动力系统维护。

### 4. MVP 基础建筑

MVP 第一版只要求以下四类建筑进入基础城市主循环：

- 房屋；
- 农田；
- 水井；
- 树场。

其他建筑可以存在于完整设计中，但不作为 MVP 第一版主循环必做内容。

### 5. MVP NPC 劳动力

MVP 中 NPC 的作用是让城市基础闭环真实运转，但不启用完整人生模拟。

MVP 必须真实保留：

- 人口数；
- 空闲 / 占用工人；
- 施工参与；
- 基础生产岗位占用；
- 房屋入住状态；
- 城市级食物 / 水消耗；
- 建筑运行或等待原因中的工人状态。

MVP 中的“空闲 NPC 参与施工 / 基础生产”不得绕过岗位权威边界，不等于系统自动替玩家确认正式岗位分配。

### 6. MVP UI

MVP 首屏至少需要：

- 木材；
- 食物；
- 水；
- 人口；
- 空闲工人；
- 时间 / 暂停状态；
- 建造入口；
- 一个非强制轻量下一步提示。

MVP 首轮建造面板必须能看到并选择：

- 房屋；
- 农田；
- 水井；
- 树场。

MVP 建筑详情 UI 至少显示：

- 建筑名称；
- 当前状态；
- 施工 / 运行 / 暂停；
- 工位状态；
- 输入资源；
- 输出资源；
- 等待原因；
- 可用 / 不可用原因。
