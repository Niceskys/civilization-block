## 本轮目标

待 Codex / 用户审核后回写。

本轮目标是为《文明块》的工具制造系统和前期启动体验之间的关系提出建议，避免后续实现时让工具系统过早卡住新手的第一轮建造、生产和探索。

建议目标包括：

1. 明确工具制造系统应服务中后期效率、深层挖掘和专业化发展，而不是阻止玩家完成第一轮基础城市闭环。
2. 明确房屋、农田、水井、树场等基础建筑不应要求玩家先完成复杂工具制造链才能开始建造。
3. 明确工具可用于施工效率、挖掘层级、维修效率、采掘效率、专业岗位能力等方向，但不应成为前30秒与前数分钟的硬门槛。
4. 明确地下挖掘、矿脉、铜镐、水晶镐、晶能镐等进阶内容可以保留工具门槛，但必须出现在玩家已完成基础生存闭环之后。
5. 本轮只提出建议，不直接修改正式 A 级文档，也不修改 Runtime、存档结构、StateHash 或联机协议。

## 建议写入内容

待 Codex / 用户审核后回写。

建议未来在 `2.4 工具制造系统.md` 中新增或补充一个“前期启动边界”小节。建议内容如下：

```md
### 前期启动边界

- 工具制造系统不作为新存档第一座建筑、第一座基础生产建筑或第一次城市响应的前置条件。
- 房屋、农田、水井、树场等基础建筑的首次建造不得要求玩家先制造工具。
- 前30秒内不得强制玩家理解工具制造、工具耐久、工具等级、工具配方或工具更换流程。
- 工具系统应在玩家完成基础城市闭环后逐步出现，包括住房、基础食物 / 水、木材补给和基础人口运转。
- 工具可以影响施工效率、维修效率、采掘效率、地下挖掘层级或专业岗位效率，但不得阻止玩家完成最小生存闭环。
- 如果未来工具影响施工速度，基础建筑的首次建造加速规则仍优先成立，工具加速不得与首次建造加速叠加造成双重加速。
- 工具耐久不足不得让已经开始的基础教学性施工直接失败；更适合作为效率下降、暂停等待或中后期维护压力。
- 深层地下挖掘、特殊矿脉、铜镐、水晶镐、晶能镐等进阶工具门槛可以保留，但应出现在基础生产链已建立之后。
```

建议未来在 `2.1 建筑通用规则.md` 中补充一句边界说明：

```md
- 基础建筑的首次建造合法性不以工具制造完成作为前置条件；工具若参与施工，只能作为效率、耐久或中后期专业化因素，不能阻止第一轮基础建筑闭环。
```

建议未来在 `10.2 任务清单.md` 中调整工具相关任务出现时机：

```md
- 工具制造任务不应排在第一座房屋、第一座农田 / 水井 / 树场之前。
- 工具制造任务更适合出现在玩家已经拥有基础住房、稳定木材来源、至少一种基础生产建筑之后。
- 第一把工具可以作为“城市开始专业化”的提示，而不是“允许开始玩游戏”的门票。
```

建议未来在实现任务中拆为以下检查项：

```md
- 检查新存档是否可以不制造工具就建造第一座房屋。
- 检查新存档是否可以不制造工具就建造第一座农田、水井或树场。
- 检查前30秒是否会出现工具制造强制教程。
- 检查工具加速是否不会与首次建造加速叠加。
- 检查地下挖掘工具门槛是否只影响对应深度，不反向卡住地面基础建造。
- 检查工具耐久耗尽时是否不会错误摧毁建筑或清空施工进度。
```

## 理由

待 Codex / 用户审核后回写。

提出本建议的理由如下：

1. 《文明块》的前期目标是让玩家快速看到城市开始响应，而不是先进入复杂工具制造教程。
2. 如果工具系统太早成为硬门槛，玩家可能在第一座房屋、第一座农田或第一口水井之前就被资源链卡住。
3. 工具系统更适合作为中后期效率、采掘深度、维修压力和专业化发展的系统，而不是第一分钟的阻塞系统。
4. 地下探索已经有明确工具层级需求，因此工具系统可以在深层挖掘中体现价值，不必提前压到地面基础建造上。
5. 首次建造加速、前30秒反馈和基础建筑闭环是新手体验重点，工具系统应避免与这些机制冲突。
6. 该建议可以降低 Codex 后续实现时把工具制造误做成全建筑前置条件的风险。
7. 把工具任务放在基础生存闭环之后，更符合“城市从能活下来到开始专业化”的成长节奏。
