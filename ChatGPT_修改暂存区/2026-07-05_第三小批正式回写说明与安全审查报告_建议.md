### 理由 1：第三小批只给四个基础建筑加 MVP 停止线


### 理由 2：本次没有删除长期机制

四个建筑文件中原有长期机制均被保留：

- 房屋保留自动入住与居住机制。
- 农田保留光照、太阳灯燃料覆盖、StateHash、服务器权威快照、施肥规则。
- 水井保留水源供给规则。
- 树场保留应急炭化和燃料链边界。

### 理由 3：本次没有改 6.1 或数值权威

四个文件中的成本、施工时长、产出、升级成本仍是受控摘要，权威仍在 6.1。

水井 10 石头成本仅记录为冷启动风险，没有直接修改。

### 理由 4：本次继续保护 MVP 范围

本次明确把以下内容排除出 MVP 第一版：

- 房屋家庭 / 生育 / 舒适度 / 情绪社交 / 完整室内模拟；
- 农田太阳灯 / 燃料覆盖 / 施肥 / 多作物 / 季节 / 病虫害；
- 水井地下水 / 水质污染 / 水桶物流 / 地下探索联动；
- 树场应急炭化 / 燃料链 / 垃圾处理场联动 / 熔炉房与太阳灯缺燃料响应；
