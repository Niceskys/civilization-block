## 本轮目标

待 Codex / 用户审核后回写。

本轮目标是在访问当前仓库分支并确认暂存区已有主题后，补充一个新的完整主题包：商店系统与非强制交易边界。当前暂存区已有“资源链冷启动与第一座熔炉房边界”文件，其中只把商店作为冷启动防卡死手段的一部分；本文件不重复该主题，而是从整体商店系统角度整理交易、补货、商品阶段、价格、任务、资源链和留存边界。

本建议的核心判断是：

> 商店系统应提供补救、选择和城市外部连接感，而不是成为基础建造、基础生产或前期留存的强制门票。

建议目标包括：

1. 明确商店不是第一座建筑、第一轮生产、第一座熔炉房或基础城市闭环的唯一解法。
2. 明确商店可承担防卡死、补货、临时交易、稀缺资源引导和外部世界感，但不得替代正式生产链。
3. 明确关键资源、工具、矿石、燃料、建筑材料的上架阶段与数量必须受限制。
4. 明确商店 UI 不能使用签到、红点轰炸、每日限时错过惩罚或强运营式留存。
5. 明确任务奖励、商店交易、生产产出必须在 UI 和事件上区分清楚，不能伪造资源来源。
6. 明确商店系统后续回写应与资源链、任务、地下探索、熔炉房、工具制造分文件小步处理。

## 建议写入内容

待 Codex / 用户审核后回写。

### 一、商店系统定位

建议未来在 `9.1 商店通用规则.md` 中形成以下原则：

```md
### 商店系统定位

- 商店系统用于提供城市外部连接感、资源补救、策略选择、阶段性稀缺资源交换和特殊商品获取。
- 商店不得成为基础城市闭环的唯一入口。
- 商店不得成为第一座房屋、第一座农田、第一口水井、第一座树场、第一座熔炉房的唯一解法。
- 玩家完全不使用商店，也应能通过建造、生产、探索、任务奖励或事件完成基础城市发展。
- 商店可以缓解卡死，但不得替代正式生产链、地下探索、工具制造或资源规划。
```

### 二、非强制交易边界

```md
### 非强制交易边界

- 前30秒不得强制打开商店。
- 不得要求玩家购买商品后才能开始第一轮基础建造。
- 不得要求玩家购买铁锭后才能建造第一座熔炉房。
- 不得要求玩家购买工具后才能建造第一座基础建筑。
- 不得把“进入商店”“购买任意商品”“领取限时礼包”作为开局主线强制步骤。
- 商店教学任务可以存在，但必须出现在基础城市闭环之后，且应允许跳过或自动延后。
```

### 三、防卡死功能建议

```md
### 防卡死功能建议

- 商店可以作为防卡死路径之一，但不应是唯一防卡死路径。
- 防卡死商品可以包括少量木材、基础食物、基础燃料、少量铁矿石、低级工具或应急材料。
- 防卡死商品的数量应有限，价格应让玩家能恢复运行但不能无限刷收益。
- 防卡死商品不应直接跳过关键生产链，只能帮助玩家重新接回生产链。
- 如果玩家因误拆、误耗尽或资源链中断而卡住，商店可提供恢复选项，但也应存在探索、任务补救、事件或低级采集等替代路径。
```

### 四、商品阶段与库存边界

```md
### 商品阶段与库存边界

- 商品应按城市阶段逐步出现，不应新存档直接展示所有高级资源。
- 基础阶段可出现少量木材、食物、水、基础燃料、低级材料。
- 加工阶段可出现少量铁矿石、少量铁锭、低级工具、熔炉辅助材料。
- 地下探索阶段可出现少量矿物样本、探索补给、低级安全工具。
- 中后期可出现铜矿石、水晶碎片、晶能相关材料、稀有装饰或特殊订单。
- 高级商品应有库存、价格、阶段、声望、事件或贸易路线限制。
- 商店库存不得无限刷新到破坏生产链价值。
```

### 五、价格与交易平衡建议

```md
### 价格与交易平衡建议

- 商店价格应高于稳定自产的长期成本，使生产链始终有价值。
- 防卡死商品可以略低门槛，但必须限制数量或补货频率。
- 稀缺资源可以价格较高，用于提供策略选择，而不是强制购买。
- 玩家不应通过反复买卖基础商品获得无风险无限收益。
- 商品售价、回收价、库存和补货周期需要进入数值模拟表验证。
- 商店不应成为绕过建筑效率、同种建筑惩罚、生产链投入和地下探索风险的套利系统。
```

### 六、资源来源标注建议

```md
### 资源来源标注建议

- 商店获得的资源必须标注为“购买”或“交易获得”。
- 任务奖励获得的资源必须标注为“任务奖励”。
- 建筑产出的资源必须标注为对应生产建筑产出。
- 探索获得的资源必须标注为探索、勘探或事件获得。
- 不得让玩家误以为商店购买资源是建筑生产结果。
- 不得让任务奖励或商店补货伪装成第一次正式资源产出。
```

### 七、商店 UI 表达建议

```md
### 商店 UI 表达建议

- 商店入口可以存在，但不得在前30秒抢占建造入口和资源栏。
- 商店提示应轻量，不强制弹窗，不遮挡建造预览或城市反馈。
- 商店商品应显示来源、库存、价格、是否限量、是否阶段解锁。
- 防卡死商品可以显示“应急补给”或“少量补货”，但不得使用强红点压迫。
- 已有稳定生产链时，商店可以提示“自产更划算”或“临时购买可补缺”。
- 不得使用签到、每日礼包、限时倒计时、错过惩罚、连续登录奖励作为商店核心 UI。
```

### 八、商店与任务系统边界

```md
### 商店与任务系统边界

- 任务可以记录第一次交易，但不得要求玩家交易后才能继续基础建造。
- 商店教学任务应可跳过、可延后、可通过自然交易自动完成。
- 任务不得强制玩家购买铁锭、燃料或工具来完成基础闭环。
- 任务奖励不得和商店购买混淆。
- 如果任务引导玩家使用商店，应明确说明这是“补救路径之一”，而不是唯一正确路径。
```

### 九、商店与外部世界感建议

```md
### 商店与外部世界感建议

- 商店可以承担世界外部连接感，例如流动商人、贸易队、附近聚落、临时订单或市场需求。
- 外部交易应服务世界感和策略选择，不应替代城市自产能力。
- 商人到访、订单刷新、稀有商品出现可以作为事件，但不得破坏基础城市闭环保护。
- 外部世界交易可以提供长期目标，例如出售加工品、完成订单、换取稀有种子或特殊蓝图。
- 商店系统应强化“城市与世界交流”，而不是变成开局付费按钮。
```

### 十、异常与防滥用建议

```md
### 异常与防滥用建议

- 如果玩家资源耗尽，商店可以提供有限恢复路径，但不得无限免费生成资源。
- 如果玩家通过买卖同一商品试图套利，价格系统应避免正收益循环。
- 如果商店库存刷新失败，不得清空玩家资源或重复发放商品。
- 如果购买后存档 / 读档，交易结果必须稳定恢复，不能重复购买或重复退款。
- 如果联机模式存在交易，必须明确交易由权威模拟结算，客户端 UI 不得直接改资源。
```

## 理由

待 Codex / 用户审核后回写。

提出本建议的理由如下：

1. 商店系统很容易从“防卡死和策略选择”滑向“强制购买和运营红点”，必须提前划边界。
2. 《文明块》的核心体验是经营建造和生产链，商店不能替代城市自产能力。
3. 资源链冷启动需要商店作为备选路径，但如果商店成为唯一解法，会削弱探索、生产和建筑系统。
4. 商品阶段和库存限制可以防止新存档直接购买高级资源，破坏成长节奏。
5. 价格和回收价如果不限制，容易形成无风险套利，影响数值平衡。
6. 资源来源标注可以防止玩家混淆“生产产出”“任务奖励”“商店购买”“探索获得”。
7. 商店也能提供世界外部连接感，因此不应完全弱化，而应放在正确阶段逐步展开。
8. 本建议已经检查当前暂存区主题，避免重复“资源链冷启动”文件，仅补充商店系统整体边界。
