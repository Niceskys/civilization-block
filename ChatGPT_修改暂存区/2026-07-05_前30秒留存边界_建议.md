## 本轮目标

待 Codex / 用户审核后回写。

本轮目标是为《文明块》的新存档前30秒体验和玩家留存方式提出建议，避免后续实现时把开局体验做成强制教程、弹窗轰炸、红点驱动或伪造资源增长。

建议目标包括：

1. 让玩家进入新存档后能马上理解“这里是一座等待启动的体素城市”。
2. 让玩家在不读长教程、不被弹窗打断的情况下找到第一步操作。
3. 保证第一次建筑放置后有明确城市响应，例如施工虚影、NPC行动、资源栏变化、建筑完成反馈。
4. 避免使用签到、红点、强制弹窗、现实时间错过惩罚等不适合《文明块》的留存手段。
5. 保证前30秒体验不伪造资源、不绕过正式生产、不改变时间系统和施工规则。
6. 本轮只提供建议，不直接修改正式 A 级文档，也不修改 Runtime、存档结构、StateHash 或联机协议。

## 建议写入内容

待 Codex / 用户审核后回写。

建议未来在 `5.7 玩家留存与分享系统.md` 中新增或补充一个“前30秒留存边界”小节。建议内容如下：

```md
### 前30秒留存边界

- 前30秒留存不依赖签到、红点、每日奖励、限时错过惩罚或现实时间活动。
- 新存档进入后，玩家应看到清楚的初始地皮、文明核心、初始NPC、资源栏和建造入口。
- 前30秒只允许展示最低必要信息：资源栏、底栏建造提示、初始地皮可建状态、NPC存在感和一个非强制推荐行动。
- 不自动打开建造面板。
- 不使用强制弹窗教程。
- 不用红点、闪烁、强音效或遮挡屏幕的“立即点击这里”。
- 第一条提示建议为轻量底栏提示，例如：`[B] 建造第一座建筑`。
- 玩家关闭提示后，本局不再强制显示同一条提示。
- 玩家未确认第一次合法建筑放置前，不应因为观察、旋转视角、打开面板或犹豫而受到时间、资源、怪物或事件惩罚。
- 第一次合法放置后，城市必须立刻给出可见反馈，包括建筑虚影 / 施工边框 / 进度表现 / NPC施工行为 / 资源栏扣除或锁定中的至少两项。
- 第一座建筑完成时，应有建筑落地、亮灯、音效、粒子或外观变化中的至少两项反馈。
- 如果第一座建筑是房屋，应优先展示自动入住、窗口暖光、床位状态变化或 NPC 进入房屋反馈。
- 如果第一座建筑是基础生产建筑，应显示“待分配 / 空闲 / 可工作”提示，不得误报红色停产危机。
- 前30秒不得伪造资源增长。第一次资源增长必须来自正式生产、任务奖励、勘探奖励、事件奖励或商店交易。
```

建议未来在 `10.2 任务清单.md` 中只记录轻量里程碑，不做强制主线：

```md
- 可记录：第一次打开建造面板。
- 可记录：第一次确认合法建筑放置。
- 可记录：第一座建筑完成。
- 可记录：第一位 NPC 入住房屋。
- 不得要求玩家先接任务才能建造。
- 不得让任务 UI 成为新手开局的唯一入口。
```

建议未来在 UI / 实现任务中拆为以下检查项：

```md
- 检查新存档30秒内是否会自动弹窗。
- 检查不操作时是否会推进正式危机或惩罚。
- 检查玩家是否能通过底栏或清晰按钮找到建造入口。
- 检查第一次合法放置后是否立刻出现施工反馈。
- 检查第一座建筑完成后是否有城市响应。
- 检查前30秒内是否存在伪造资源增长。
- 检查任务系统隐藏时，开局体验是否仍可成立。
```

## 理由

待 Codex / 用户审核后回写。

提出本建议的理由如下：

1. 《文明块》的核心吸引力应来自体素城市开始运转，而不是强制教程和红点奖励。
2. 玩家前30秒最需要的是“我能做什么”和“我的操作产生了回应”，不是完整理解全部系统。
3. 如果新手体验依赖任务弹窗，玩家会误以为游戏是线性任务驱动，而不是开放经营建造。
4. 如果前30秒伪造资源增长，会破坏生产链和任务奖励的可信度。
5. 如果刚开局就推进时间、怪物、危机或资源惩罚，会惩罚观察型玩家，不利于体素城市观赏和规划。
6. 使用轻量底栏提示、建造反馈、NPC行为、暖光反馈，比签到和红点更符合《文明块》的气质。
7. 本建议能够与已存在的首次合法建筑放置、时间启动、首次建造加速、自动入住等规则保持一致，不需要扩大 Runtime 范围。
