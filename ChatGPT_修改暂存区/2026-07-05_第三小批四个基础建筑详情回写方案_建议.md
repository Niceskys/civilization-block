## 建议任务 S9：`房屋.md`

### 文件现状

房屋文件已有建造成本、首次房屋加速、居住容量、床位、自动入住、NPC 创建顺序分配、空床位排序、不驱逐 / 不交换 / 不重排、玩家手动分配优先、房屋失效后失去床位、无家可归状态等规则。

### MVP 判断

房屋是四个基础建筑中最稳定、最适合直接进入 MVP 的建筑。MVP 应保留床位、自动入住、居住容量反馈，但不展开家庭、生育、舒适度、情绪、社交、记忆或完整室内模拟。

### 建议写入内容

```md
### MVP 职责与停止线

房屋在 MVP 中承担居住容量、自动入住反馈和人口稳定入口。

MVP 必须保证：

- Lv1 房屋提供有效床位。
- 房屋完成施工后能够触发一次自动入住结算。
- 建筑详情或相关 UI 能显示床位占用状态。
- 无床位 NPC 可以被解释为等待住房或无家可归。
- 房屋只负责居住，不负责工作或职业分配。

MVP 不要求实现：

- 家庭关系；
- 生育；
- 舒适度；
- 情绪、社交、好感度、记忆；
- 完整房屋内部模拟；
- 房屋升级链。
```

### 禁止事项

- 不删除现有自动入住规则。
- 不把家庭、生育、舒适度、复杂室内模拟写成 MVP 必做。
- 不修改 6.1 中的房屋数值。

## 建议任务 S10：`农田.md`

### 文件现状

农田文件已有建造成本、首次基础生产建筑加速、运行消耗水、工人上限、基础食物产出、光照规则、Runtime 光照规则、太阳灯燃料覆盖、StateHash / 服务器权威快照、施肥规则等内容。

### MVP 判断

农田必须进入 MVP，但只承担基础食物来源。MVP 不应把完整光照、太阳灯、燃料覆盖、StateHash、服务器权威、施肥等规则列为第一版必做。

### 建议写入内容

```md
### MVP 职责与停止线

农田在 MVP 中承担基础食物来源。

MVP 必须保证：

- 农田可以消耗水并周期产出食物。
- 农田至少需要基础工位或有效劳动力参与。
- 农田在缺水、缺工人或建筑不可运行时显示明确等待原因。
- 农田产出属于真实生产结果，不得由任务、商店或 UI 伪造。

MVP 不要求实现：

- 完整光照遮挡系统；
- 太阳灯恢复生产；
- 太阳灯燃料覆盖；
- 施肥系统；
- 多作物、季节、病虫害、土壤肥力；
- 农田升级链。

现有光照、太阳灯、燃料覆盖、施肥等规则保留为后续扩展，不作为 MVP 第一版必做。
```

### 禁止事项

- 不删除现有 Runtime 光照或施肥规则。
- 不把太阳灯、燃料覆盖、StateHash、服务器权威写成 MVP 必做。
- 不把农田升级链写成 MVP 必做。
- 不修改 6.1 中的农田数值。

## 建议任务 S11：`水井.md`

### 文件现状

水井文件已有建造成本 10 石头、首次基础生产建筑加速、工人上限、产水、无运行消耗、升级、水进入全局水库存、NPC 每日消耗水、农田灌溉耗水等内容。

### MVP 判断

水井必须进入 MVP，作为基础水来源。水井机制相对简单，但存在冷启动风险：当前建造成本为 10 石头，而第一小批 MVP 主循环资源子集不包含石头。

第三小批只记录这个风险，不直接修改成本。水井成本应由 `6.1 建筑数值表` 或后续 MVP 初始资源裁决处理。

### 建议写入内容

```md
### MVP 职责与停止线

水井在 MVP 中承担基础水来源。

MVP 必须保证：

- 水井能够产出水。
- 水能够进入城市水库存或等价水状态。
- 水可用于 NPC 生存消耗与农田灌溉。
- 水井在缺工人或不可运行时显示明确等待原因。

MVP 不要求实现：

- 水井升级链；
- 自动运转；
- 地下水位；
- 水质和污染；
- 水桶物流；
- 井深升级；
- 地下探索联动。

注意：水井建造成本由 6.1 维护。若 MVP 不引入石头生产，需通过初始资源或数值表裁决解决水井冷启动问题。
```

### 禁止事项

- 不直接修改水井成本。
- 不把自动运转、地下水、水质污染、水桶物流写成 MVP 必做。
- 不把地下探索联动写成 MVP 必做。
- 不修改 6.1 中的水井数值。
