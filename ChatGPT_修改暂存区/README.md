# ChatGPT 修改暂存区

本文件夹用于存放由 ChatGPT 辅助生成、修改或整理的“文明块”相关内容。

## 用途

- 这里的内容属于临时修改区，不直接视为正式游戏设计或正式源文件。
- 所有内容需要经过用户在电脑端使用 Codex / 本地工具审核后，再决定是否移动、合并或回写到正式“文明块”文件夹中。
- ChatGPT 后续可以优先把待审核内容写入本文件夹，避免直接污染正式文档结构。

## 使用规则

1. 本文件夹内的内容默认都是“待审核”状态。
2. 未经用户明确要求，不直接修改正式源文件。
3. 每次新增或修改内容时，应尽量说明：修改目标、涉及机制、是否影响正式规则。
4. 通过 Codex 或人工审核确认后，再由用户决定是否合并到正式目录。
