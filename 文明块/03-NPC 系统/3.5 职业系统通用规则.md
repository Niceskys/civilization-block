# 职业系统通用规则

> 权威边界：本文件维护职业学习、职业数量、转职规则和职业外观边界；职业与多职业效率倍率以6.2为唯一数值源，岗位分配与重新分配流程以3.3为准。NPC基础生命周期、住房、社交和记忆规则分别以3.1、3.7、3.8及相关文件为准。

### 职业外观与体素人物边界

- [x] NPC人物必须保持明确体素块状风格，采用方块头、长方体身体、长方体手臂、长方体腿部、块状手脚、平面脸和像素贴图表达。
- [x] 禁止将NPC做成圆头、圆身、圆润四肢、平滑低模卡通人体或软胶玩具感角色。
- [x] 人物造型可以参考方块体素角色的基础逻辑，但不得直接照搬Minecraft具体角色比例、皮肤、服装、脸部、村民造型或标志性资产。
- [x] 职业差异主要通过服装贴图、工具、配件、姿态和状态表现体现，而不是通过改变为写实或圆润人体比例体现。
- [x] NPC精细感来自服装颗粒、职业服饰、工具腰带、围裙、护腕、背包、帽子、块状头发层次、武器挂点、使用痕迹、年龄差异和状态贴图。
- [x] 职业外观不得影响职业倍率；职业倍率仍以6.2为唯一数值源。

#### 职业外观示例

| 职业类型 | 建议视觉识别 | 禁止方向 |
|---|---|---|
| 农夫 | 草帽或头巾、布料衣服、简单围裙、泥土痕迹、农具挂点 | 圆润Q版农夫或写实人体比例 |
| 工匠 | 工作围裙、工具腰带、手套、灰尘/铁屑贴图、锤子或钳子 | 写实肌肉工匠、圆润手套角色 |
| 守卫 | 块状头盔、护肩/胸甲、武器挂点、硬朗色彩 | 平滑骑士低模、圆形头盔人偶 |
| 儿童 | 方块头、短身体和短四肢、简单服饰 | 圆脸Q版儿童 |
| 老年NPC | 块状结构不变，以发色、胡须、衣服磨损和姿态区分 | 通过圆润脸型或写实皱纹建模区分 |

### 核心效率规则（基础设定）
- [x] 无职业、职业匹配和职业不匹配使用不同效率倍率，具体数值以6.2为准
- [x] 职业加成与属性加成的计算方式：**相乘**
  - 岗位基础效率 = 职业匹配倍率 × 属性适配倍率
  - 性格情境效果由6.2单独定义，不属于职业倍率
  - 公式数值见6.2；分配应用流程见3.3

### 职业获取规则
- [x] 职业确定时机：玩家手动分配
- [x] 初始可选择职业数量：8种（全部可用，部分需建筑解锁后触发）
- [x] 高级职业解锁条件：科技解锁 / 商店购买建筑后可用
- [x] 每名NPC最多拥有 3 个职业
  - 多职业规则：
    - 第1、第2、第3职业使用不同匹配倍率，具体数值以6.2为准
    - 同一时间只能从事 1 个职业的工作
- [x] 学习新职业的消耗/条件：消耗50星辉 + 学习时间1游戏日（期间不能工作）

### 转职规则
- [x] NPC是否可以更换职业：是（玩家手动操作）
- [x] 转职是否有冷却时间：是，冷却时长：2 游戏日
- [x] 转职是否消耗资源/货币：是，消耗：50 星辉/次
- [x] **转职后原职业是否保留：是**（已学职业永久保留，NPC最多积累3个职业）

### 职业与属性关联
- [x] 属性是否影响职业适配度：是（每职业有3偏好属性，按权重计算适配倍率）
- [x] 高属性NPC是否可解锁特殊职业：否（所有职业均可通过学习获得）
- [x] 职业是否会随工作经验升级：是 → 科技树社会Lv5解锁"大学"后，NPC可自学提升职业等级
