# 00.27 前30秒与首次城市响应规则 v1

> 本文件承接RW10-B“前30秒与任务/留存回写”。它只定义首次进入存档、第一次观察、第一次建造提示和第一次城市响应的体验边界，不修改Runtime、施工时长、资源产出、存档、StateHash或联机协议。

---

## 一、核心目标

前30秒的目标不是教完系统，而是让玩家立刻理解三件事：

1. 这里是一座可以生长的体素城市；
2. 我可以马上做第一件事；
3. 城市会对我的操作产生可见回应。

核心体验句：

> 玩家进入世界后，不应先读规则，而应先看到城市在等待他开始。

### MVP 首轮体验边界

本文件属于 MVP 首轮体验的正式边界之一。

MVP 前30秒只服务“让城市开始动起来”，不展示完整系统规模。

前30秒不得把以下系统作为玩家首轮必须理解或必须操作的内容：

- 正式任务系统；
- 商店系统；
- 地下探索；
- 工具制造；
- 科技树；
- 怪物 / 防御战；
- 完整 NPC 职业、情绪、记忆或社交；
- 联机入口；
- 模组入口。

这些系统可以属于长期设计，但不得干扰新存档第一轮基础城市启动。

---

## 二、开局状态

- [x] 新存档进入后，世界默认处于暂停或未推进状态。
- [x] 初始2×2四块地皮已经完成基础勘探，可直接建造，不显示未勘探阻挡。
- [x] 初始NPC可以有轻微待机动画、转头、站立、短距离走动或看向文明核心的表现，但不得消耗资源、触发危险或推进正式生产。
- [x] 时间推进的正式触发仍以`1.3 时间系统规则`和`2.1 建筑通用规则`为准：第一次合法确认建筑放置并创建施工任务后，世界进入正常时间推进。
- [x] 玩家在未确认第一次建筑放置前，可以观察、旋转视角、打开建造面板、查看资源和NPC，但不会因为犹豫而受到惩罚。

---

## 三、前30秒信息层级

前30秒只允许出现最低必要信息：

- 当前资源栏；
- 初始地皮可建状态；
- NPC存在感；
- 底栏快捷键提示；
- 一个非强制推荐行动。

禁止在前30秒内同时展示复杂面板、任务列表、职业公式、生产链详情、敌袭说明、商店促销、季节活动、签到式提示或大段剧情说明。

---

## 四、提示规则

- [x] 不自动打开建造面板。
- [x] 不使用强制弹窗教程。
- [x] 不使用红点、闪烁、强音效或遮挡屏幕的“立即点击这里”。
- [x] 第一条提示使用底栏或轻量提示条，例如：`[B] 建造第一座建筑`。
- [x] 玩家打开建造面板后，房屋卡片可以显示“推荐”标签，但不得锁定其他建筑选择。
- [x] 玩家关闭提示后，本局不再强制显示同一条提示；可在帮助/引导页面重新打开。

---

## 五、第一次城市响应

第一次城市响应指玩家进行第一个有效操作后，城市必须立刻给出可见反馈。

### 5.1 打开建造面板后的反馈

- 建造面板打开动画简短、清楚，不遮挡城市主体。
- 初始建筑中优先推荐房屋，但农田、水井、树场等基础建筑仍可选择。
- 建筑预览必须清楚显示合法/非法位置。
- 合法位置显示绿色或青色虚影；非法位置显示红色虚影和简短原因。

### 5.2 确认第一座建筑后的反馈

- 创建施工任务后，建筑虚影、施工边框、进度环或阶段性形变必须立刻出现。
- 至少1名可用NPC应进入施工表现状态，前往工地或做施工动画。
- 资源栏应即时扣除或显示已锁定资源。
- 底栏应提示世界时间已开始流动，但不得弹窗打断。

### 5.3 第一座建筑完成后的反馈

- 建筑完成时必须有落地、亮灯、音效、粒子或外观变化中的至少两项反馈。
- 如果第一座是房屋，应触发自动入住反馈：NPC进入房屋、窗口暖光、床位状态更新。
- 如果第一座是基础生产建筑，应进入待分配工人或可工作状态，使用“空闲/待分配”提示，不得误用停产红色告警。

---

## 六、堆叠首次提示

- 堆叠提示不应等到玩家已经造出很多建筑后才出现。
- 玩家第一座建筑完成后，再次进入建造模式并把鼠标/光标移过可作为底层的建筑顶部时，显示顶部可建造网格。
- 首次吸附到建筑顶部时，底栏显示一次轻提示：`建筑也可以建在其他建筑上方。`
- 该提示不强制玩家堆叠，不阻止地面建造，不弹窗，不重复轰炸。
- 堆叠合法性继续遵守`2.1`、`2.2`和三维占地/承重正式规则。

---

## 七、真实反馈边界

- [x] 不赠送不存在的“启动资源”。
- [x] 不伪造食物、水、木材或星辉增长。
- [x] 第一次资源增长必须来自正式生产、任务奖励、勘探奖励、事件奖励或商店交易。
- [x] 建筑刚建成时可以有视觉和音效反馈，但不能假装已经产生资源。
- [x] 如果当前生产系统无法在前30秒内产生真实资源，前30秒留存应依靠建造反馈、NPC反馈、城市光影和堆叠预告，而不是虚假产出。

---

## 八、任务系统边界

- 发展篇章可以在后台记录“打开建造面板”“确认第一座建筑”“完成第一座建筑”等里程碑。
- 前30秒不显示完整任务清单，不要求玩家接取任务，不用任务弹窗推动玩家。
- 任务提示不得成为第一座建筑放置的前置条件。
- 玩家隐藏任务UI后，前30秒体验仍应完整成立。

---

## 九、验收标准

RW10-B验收时至少检查：

- 进入新存档后30秒内不出现强制弹窗；
- 初始四块地皮可直接建造；
- 玩家不操作时，时间不推进且无惩罚；
- 玩家能在轻提示下找到建造入口；
- 第一次合法放置后立刻有施工反馈；
- 第一次施工反馈中至少包含建筑视觉变化和NPC行为；
- 房屋完成后有自动入住或暖光反馈；
- 生产建筑完成后提示为待分配/空闲，而不是红色停产危机；
- 不产生虚假资源；
- 堆叠提示以轻量方式在第一次建筑完成后可被发现。

---

## 十、禁止事项

- 不把前30秒做成强制教程关卡。
- 不自动打开建造面板。
- 不用弹窗遮住城市。
- 不用红点和签到式留存手段。
- 不让任务系统成为开局唯一驱动力。
- 不伪造第一次资源增长。
- 不让玩家因为观察和犹豫受到时间、资源、危机或怪物惩罚。
- 不在本文件中修改施工时长、资源产出周期或怪物规则。
