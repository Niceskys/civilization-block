# 第十一轮：精细体素美术风格裁决 v1.0

> 本文件记录第十一轮关于《文明块》视觉风格、人物造型、建筑贴图、光影渲染和性能边界的裁决。  
> 本文件属于B级治理材料。正式生效需回写至对应A级源文件。

---

## 一、总风格定义

《文明块》的视觉风格正式定为：

> 高细节像素贴图体素风。

它不是粗颗粒低模体素，不是圆润低模卡通，也不是表面平滑、贴图单调的普通体素风。

核心目标：

> 结构必须是体素的，贴图必须是精细的，光影必须突出颗粒和层次。

视觉关键词：

- 清晰方块结构；
- 精细像素贴图；
- 丰富材质变化；
- 明显颗粒感；
- 非重复墙面；
- 清晰阴影；
- 昼夜氛围；
- 建筑状态光；
- 内部建筑精细界面。

---

## 二、人物体素标准

人物必须保持明确体素块状风格。

### 2.1 必须采用

- 方块头；
- 长方体身体；
- 长方体手臂；
- 长方体腿部；
- 块状手脚；
- 平面脸；
- 像素贴图表达。

### 2.2 禁止采用

- 圆头；
- 圆身；
- 圆润四肢；
- 平滑低模卡通人体；
- 软胶玩具感角色。

人物造型可以参考方块体素角色的基础逻辑，即“方头、方身、方手方脚、平面脸、像素贴图”，但不得直接照搬Minecraft具体角色比例、贴图、皮肤、服装或标志性形象。

### 2.3 精细感来源

人物精细感来自：

- 服装纹理；
- 职业服饰；
- 工具腰带；
- 围裙；
- 护腕；
- 背包；
- 帽子；
- 头发块状层次；
- 武器挂点；
- 使用痕迹；
- 年龄差异；
- 状态贴图。

精细感不得通过圆润化实现。

---

## 三、建筑与贴图标准

建筑必须是体素块状建筑，而不是普通低模建筑贴像素图。

每座建筑应具备：

- 块状主体；
- 清晰屋顶；
- 明确窗户；
- 可识别入口；
- 体素边缘；
- 材质分区；
- 局部装饰；
- 状态表现。

### 3.1 墙面禁止单调重复

大面积墙面不得只使用单一平铺贴图。

墙体必须支持：

- 主纹理；
- 变体纹理；
- 边缘纹理；
- 窗边纹理；
- 底部脏污；
- 屋檐阴影；
- 局部裂纹；
- 局部磨损；
- 高度差异；
- 使用痕迹。

同一种材料可以统一，但不能死板复制。

### 3.2 材料家族系统

基础材料家族包括：

- 木材；
- 石头；
- 砖石；
- 泥土；
- 草地；
- 金属；
- 布料；
- 玻璃；
- 屋顶材料；
- 发光材料；
- 装饰材料。

每个材料家族至少应具备基础纹理、变体纹理、边缘纹理、磨损纹理和状态纹理。

---

## 四、建筑状态可视化

建筑外观必须反映状态。

| 建筑状态 | 视觉表现 |
|---|---|
| 新建完成 | 材质干净，边缘清楚 |
| 正常运行 | 轻微状态光或活动表现 |
| 缺工人 | 状态图标或暗淡表现 |
| 缺资源 | 入口/工作区弱化 |
| 损坏 | 裂纹、破损边缘、暗色区域 |
| 升级后 | 外形、屋顶、装饰和内部结构更丰富 |
| 夜晚有人居住 | 窗户暖光 |
| 生产中 | 烟、火光、粒子、局部亮度 |

视觉必须服务玩法反馈，而不是只作为装饰。

---

## 五、地形与自然美术

地皮必须有体素边界和厚度，不能只是平面网格。

地皮应表现：

- 清晰边缘；
- 立方体厚度；
- 草地/泥土/石头分层；
- 边缘颗粒；
- 高度感；
- 地皮柱状感。

草地、土壤、石路不能大面积纯色或单调重复。树木和植被必须保持块状树干、块状树冠、细节贴图和体素叶片层次，禁止圆形低模树冠作为正式路线。

---

## 六、内部建筑视角美术

建筑内部视角是重要吸引点。

内部必须是“精细配置界面 + 半可视化房间”，而不是单纯表格面板。

内部应包含：

- 房间结构；
- 体素家具；
- 工具架；
- 墙面贴图；
- 地板细节；
- 灯光；
- 状态动画；
- 装饰槽；
- 人员站位；
- 功能区域。

内部视角只在打开时加载或显示，不作为全地图常驻实时渲染对象。

---

## 七、光影与渲染裁决

推荐主路线：

> Unity + C# + URP + 自定义体素风Shader + 分层渲染 + 画质分档。

光影目标：

- 方向性阳光；
- 黄昏长阴影；
- 夜晚暖窗光；
- 体素环境遮蔽；
- 上下层明暗差；
- 建筑状态光；
- 局部生产光效；
- 室内高质量局部光影。

### 7.1 光源规则

| 光源 | 处理方式 |
|---|---|
| 太阳 | 主阴影来源 |
| 月光 | 简化阴影或低强度环境光 |
| 房屋窗户 | 发光材质，不投实时阴影 |
| 熔炉火光 | 局部氛围光，低成本 |
| 工坊火花 | 粒子和发光表现 |
| 太阳灯 | 可显示覆盖范围，有限局部光 |
| 哨塔灯 | 状态提示光 |
| 装饰灯 | 默认不投实时阴影 |

### 7.2 体素环境遮蔽

体素AO必须用于强化方块边缘、墙角、屋檐、地基、堆叠接触面、多层城市阴影和室内家具层次。AO目的不是写实，而是突出体素颗粒和体块层次。

---

## 八、技术边界

体素颗粒感必须靠模型结构、贴图细节、Shader、AO、阴影和材质变体实现，不得靠每个小体素块独立GameObject堆出来。

正式禁止：

1. 圆头圆身低模卡通人物；
2. 平滑低模建筑；
3. 大面积纯色墙面；
4. 单一贴图无限重复；
5. 每个小体素块独立实时渲染；
6. 全局大量动态阴影灯；
7. 过度Bloom导致体素边缘模糊；
8. 过度写实材质导致方块风格消失；
9. 直接复刻Minecraft官方贴图或角色形象；
10. 把“精细”理解为杂乱堆装饰。

---

## 九、MVP美术最低标准

MVP至少验证：

1. 方块人物原型；
2. 方块建筑原型；
3. 建筑基础贴图颗粒；
4. 墙面非纯色；
5. 白天/黄昏/夜晚基础光照；
6. 房屋夜晚暖窗光；
7. 熔炉房运行光效；
8. 农田、地皮、墙体基础材质差异；
9. 工坊或熔炉房内部视角示范；
10. 体素边缘和AO初步表现。

---

## 十、最终裁决

《文明块》要让玩家远看觉得这是一座清晰的立体体素城市，近看觉得每一块墙、每一个人、每一座建筑内部都有颗粒、有痕迹、有生活。
