# 第十轮：核心玩法定位裁决 v1.0

> 本文件记录第十轮关于《文明块》核心乐趣、开局吸引、后期节奏、性能预算和建筑内部视角的裁决。  
> 本文件属于B级治理材料。正式生效需回写至对应A级源文件。

---

## 一、核心乐趣定位

《文明块》的核心乐趣定为：

> 在有限地皮上，把一个小营地逐渐堆叠成有生命、有记忆、有生产链的立体文明。

关键词：

1. 有限地皮；
2. 竖向体素城市成长；
3. 生产链自转；
4. NPC文明记忆；
5. 低频危机与守护感。

《文明块》不是普通城市建造、硬核塔防、复杂物流模拟、纯NPC模拟器或任务驱动手游。防御、任务、科技、工具和装饰都必须服务于“竖向城市成长、生产链自转、NPC文明痕迹”。

---

## 二、核心乐趣排序

### 2.1 第一核心：空间成长感

玩家应感到：

> 我的城市长高了。

从初始有限地皮开始，玩家逐步通过屋顶、上层建筑、连廊、管道、太阳灯和高层功能，把小营地发展成区块柱式立体城市。

### 2.2 第二核心：生产链成长感

玩家应感到：

> 我的城市开始自我运转。

生产链从食物、水、木材，逐步进入铁矿石、铁锭、燃料、工坊、工具、太阳灯、仓库和管道。资源链要清晰、有瓶颈，但不能卡死或压过竖向建造。

### 2.3 第三核心：NPC记忆感

NPC不是效率单位，而是城市历史的载体。重点事件包括：第一个入住者、第一个孩子、第一个守夜人、第一个工匠、第一个牺牲者、第一代老去和死亡生平总结。

### 2.4 第四核心：低频危机感

夜晚、怪物和防御是节奏调味，不是主玩法。它们用于让玩家意识到城市会受伤，需要守护、修复和纪念。

---

## 三、前30秒吸引机制

前30秒的目标不是展示复杂系统，而是让玩家完成“第一次城市响应”。

开局设计：

1. 玩家看到4块初始地皮和4名居民；
2. 时间暂停；
3. 城市脉搏条提示：4名居民没有住所，放下第一座建筑后时间开始流动；
4. 第一次只推荐房屋、农田、水井三类建筑；
5. 放置时显示后果预览；
6. 确认后时间流动，NPC立刻行动，城市状态变化。

正式裁决：

> 前30秒必须让玩家感到“我的第一个决定让城市活了”。

## 四、后期时长与防挂机原则

普通玩家目标体验：

- 20-30小时进入中后期；
- 40-60小时形成成熟城市；
- 60-100小时进入完整后期文明；
- 100小时以上继续沙盒扩展。

推荐关键节点：

| 目标 | 推荐达成时间 |
|---|---:|
| 第一个稳定营地 | 30-60分钟 |
| 第一次入夜完整体验 | 20分钟内 |
| 第一名婴儿出生 | 2-4小时 |
| 第一次二层建筑 | 3-5小时 |
| 第一座采掘场 | 5-8小时 |
| 第一座熔炉房 | 7-12小时 |
| 第一批铁锭 | 8-13小时 |
| 第一座太阳灯 | 10-16小时 |
| 第一件工具 | 12-18小时 |
| 人口10 | 15-25小时 |
| 10层垂直城市 | 25-40小时 |
| 第一次BOSS | 35-60小时 |
| 人口50/成熟文明 | 60-100小时 |

防挂机原则：后期推进不能只依赖资源等待，而应同时依赖空间规划、承重、光照、燃料、人口、防御、工业、探索和NPC传承。

## 六、建筑内部视角

建筑内部视角不是全量实时模拟，而是“精细配置界面 + 半可视化房间”。

内部视角可调整：

- 人员；
- 工具；
- 路线；
- 配方；
- 队列；
- 生产偏重；
- 装饰；
- 升级模块。

关闭内部视角后，系统保存配置参数、效率参数和状态值，在上帝视角按公式持续模拟。

工坊示例：

- 工具优先；
- 武器优先；
- 维修优先；
- 均衡生产；
- 手动队列。

内部精细建筑优先级：房屋、工坊、熔炉房、仓库、哨塔、农田、水井、树场。

## 七、技术路线边界

首发继续采用：

> Unity + C# + URP + 数据驱动模拟架构。

不得在MVP阶段因为性能焦虑更换引擎、改用Unreal、重写C++核心或全量迁移DOTS。后期可根据Profiler结果局部使用Job System、Burst和Entities/ECS。

核心原则：

> 《文明块》的性能不是靠换语言救，而是靠把城市做成数据系统，把画面做成状态表现。
