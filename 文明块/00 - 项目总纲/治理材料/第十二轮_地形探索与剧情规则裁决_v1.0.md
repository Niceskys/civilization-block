# 第十二轮：地形探索与剧情规则裁决 v1.0

> 本文件记录关于未知区域、地形过渡、新区块接入、文明化过渡层和剧情解释的裁决。  
> 本文件属于B级治理材料。正式生效需回写至对应A级源文件。

---

## 一、总原则

《文明块》的地形与探索规则采用以下原则：

> 视觉上可以精细起伏，规则上必须清楚可建。

地形可以有体素颗粒、高低起伏、边缘过渡和自然破碎感，但建筑放置不得按每个小颗粒逐像素判定。建造必须基于清楚的建造层、地基面、占地和承重规则。

---

## 二、未知区域规则

未知区域不是普通视线遮挡，而是未被文明核心记录和稳定的区域。

区域状态分为：

| 状态 | 表现 | 操作 |
|---|---|---|
| 未发现 | 黑雾、暗色剪影或不可见 | 不可建造，不显示资源 |
| 已侦察 | 粗略轮廓可见 | 可判断大致高度和风险，不可建造 |
| 已测绘 | 地形细节可见 | 可规划，不可正式建造 |
| 已锚定 | 完整显示并接入城市 | 可建造、可改造、可管理 |

核心解释：

> 玩家不是看不见世界，而是文明尚未记录世界。

---

## 三、建造层与地形颗粒

地形规则分为两层：

### 3.1 建造层

建造层是规则高度，用于建筑放置、承重、遮挡、连接和层级管理。

示例：

- 第0层地面；
- 第1层建筑；
- 第2层建筑；
- 第3层建筑。

### 3.2 地形颗粒

地形颗粒是视觉高度，用于草地、碎石、小土坡、边缘颗粒、贴图起伏和破碎感。

地形颗粒不应单独阻止建筑放置。

---

## 四、建造与整地规则

| 地形情况 | 处理方式 |
|---|---|
| 草、碎石、小颗粒 | 自动清理或覆盖 |
| 1/8或1/4建筑高度起伏 | 自动找平 |
| 同一建造层轻微不平 | 可建造，生成地基边缘 |
| 接近半层高差 | 需要地基、平台或支柱 |
| 1个完整建造层高差 | 需要楼梯、平台、支柱或地形改造 |
| 2层以上高差 | 普通建筑不能直接放置，需平台/支撑/整地 |
| 悬崖边 | 需要特殊高台地基或支撑 |
| 水边/坑洞边 | 需要桥基、木桩或填土 |

默认不强迫玩家手动铲平轻微不平。手动整地作为中后期高级规划工具存在。

---

## 五、文明化过渡层

建筑不得直接裸压在高差地形上。

当建筑放置在存在可见高差的地形上时，系统必须生成文明化过渡层，避免出现“建筑压在裸露泥土柱上”的突兀效果。

文明化过渡层包括：

- 石质地基；
- 木质平台；
- 挡土墙；
- 地基裙边；
- 台阶；
- 支柱；
- 桥接结构；
- 草边或石边过渡。

规则：

| 高差 | 处理方式 |
|---|---|
| 小颗粒起伏 | 自动覆盖 |
| 低于半层 | 自动生成薄地基边框 |
| 接近1层 | 自动生成地基裙边或挡墙 |
| 1完整层 | 必须生成台地、平台、支柱或挡墙 |
| 2层以上 | 需玩家先进行平台、支撑或整地 |

核心句：

> 地形可以有高差，但建筑与地形之间必须有文明化过渡层。

---

## 六、新区块接入规则

新区块不是默认平整空地，而是带有可控高差、地形属性和接驳边的城市扩张单元。

新区块不默认完全铲平，但必须具备可建造核心面与接驳边。

### 6.1 区块接驳边

新区块与旧城市相邻时，系统识别连接边，形成区块接驳边。

接驳边负责：

- 连接道路、平台和连廊；
- 避免裸土断层；
- 自动补充挡土墙、台阶、桥基或地基；
- 让新区块可以被城市接入。

### 6.2 新区块地形类型

| 类型 | 特点 | 处理方式 |
|---|---|---|
| 平缓区块 | 与旧城高度接近，小颗粒起伏 | 不需铲平，自动接驳 |
| 台地区块 | 高或低1个建造层 | 自动生成台阶、挡墙、平台或短桥 |
| 复杂区块 | 坡地、石脊、小坑、水边、矿点 | 中后期出现，需要规划和可选整地 |

### 6.3 整备方式

新区块解锁后提供三种整备方式：

| 方式 | 效果 |
|---|---|
| 保留地形 | 保留自然高差，生成基础接驳边 |
| 局部整备 | 平整主要建造面，保留边缘层次 |
| 完全整地 | 消耗资源，整理成标准建造面 |

默认推荐：局部整备。

核心句：

> 新区块不是被铲平成平板，而是被城市接入和驯化。

---

## 七、横向扩张与竖向建造

横向扩张困难是核心设定。困难不是禁止横向扩张，而是让地皮变成重要选择。

横向扩张需要：

- 探索；
- 测绘；
- 星辉锚定；
- 接驳边处理；
- 文明化过渡层；
- 资源投入。

向上建造更自然，因为它发生在已有文明边界内，成本更低、风险更小、接入更稳定。

---

## 八、剧情解释重构

原先普通经营剧情不足以解释未知区域、区块限制和横向扩张困难，因此采用新世界观框架：

> 世界曾经完整，后来因“断界”破碎成无数区块。未被文明记录的区域被灰雾覆盖。玩家掌控文明核心，能照亮、测绘、锚定和管理区块。NPC是跟随文明火种重建生活的人。

### 8.1 核心概念

#### 文明核心

玩家管理中心，负责显示已知区域、记录NPC、管理资源、锚定区块、支持建造和保存城市历史。

#### 星辉

不是普通货币，而是文明核心用于扩张、解锁、锚定、修复边界和记录里程碑的稳定能量。

#### 未锚定区块

未知区域，地形、资源、危险和结构均不稳定，无法直接建造，需要探索、测绘和锚定。

#### 文明化过渡层

新区块接入后由城市生成的地基、挡墙、台阶、平台、支柱、桥接和道路接口。

## 九、玩法与剧情对应

| 玩法问题 | 剧情解释 |
|---|---|
| 为什么未知区域看不见 | 文明核心未测绘，无法解析 |
| 为什么不能直接建造 | 未锚定区块不稳定 |
| 为什么要花星辉 | 星辉用于锚定和稳定区块 |
| 为什么横向扩张困难 | 新区块需要测绘、接驳、稳定 |
| 为什么上下建造更自然 | 已锚定区块内部更稳定 |
| 为什么新区块有过渡结构 | 文明核心生成文明化接驳层 |
| 为什么NPC不能随便去未知区 | 灰雾区危险且无核心保护 |
| 为什么有里程碑 | 文明核心记录城市历史 |
| 为什么NPC记忆重要 | 文明重建依靠记录和传承 |

---

## 十、最终裁决

《文明块》的世界不是普通连续大陆，而是由破碎区块组成的块界。玩家掌控文明核心，只能完整感知、管理和建造已测绘并锚定的区块。探索负责揭示轮廓，测绘负责确认地形，星辉锚定负责接入城市。横向扩张困难来自新区块测绘、锚定和接驳成本；向上建造更容易，因为它发生在已有文明边界内。

最关键的一句话：

> 玩家不是看不见世界，而是文明尚未记录世界。
